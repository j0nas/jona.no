The aim is to get comfortable reading and reviewing Rust, much of which will be written by agents, and to judge when Rust is a better fit than Node. The exercises have me predict what code does, fix code that doesn't compile, review plausible agent-written code for problems and implement small functions. Each lesson ends with how its topic changes the choice between Rust and Node.
